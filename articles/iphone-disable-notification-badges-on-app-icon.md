iPhoneを開いた瞬間, **メールアプリのアイコンに赤いバッジ**が付いているのが目に入り, つい開いてしまった. そんな経験はないでしょうか.

![notification-badge](/images/iphone-disable-notification-badges-on-app-icon/notification-badge.jpeg)

著者はメールをこまめに確認してしまう性格なので, 「メールはこの時間だけ確認する」とルールを決めています. しかし, バッジが見えている限り「今は見ない」と自分に言い聞かせ続けることになり, そのたびに集中力が削られていました. 結局アプリを開いてしまうことも少なくありません.

**解決策はシンプルで, アプリごとに通知バッジをオフにするだけです.**

# バッジをオフにする手順

1. 「設定」アプリを開く

2. 検索欄にアプリ名を入力し, そのアプリの設定を開く

3. 「通知」を開く

4. 「バッジ」をオフにする

これだけです. 「設定」→「通知」のアプリ一覧から目的のアプリを探しても, 同じ画面に辿り着けます.

なお, この設定はアプリごとに行うものです. 全アプリのバッジをまとめてオフにする項目はないようなので, 気になるアプリを1つずつ設定する必要があります.

## オフにする前後の比較

実際にメールアプリのバッジをオフにした結果が次のとおりです.

| オフにする前                                                                                                         | オフにした後                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| ![バッジありのホーム画面](/images/iphone-disable-notification-badges-on-app-icon/iphone-has-notification-badge.jpeg) | ![バッジなしのホーム画面](/images/iphone-disable-notification-badges-on-app-icon/iphone-non-notification-badge.jpeg) |

メール系アプリをまとめたフォルダに付いていた赤い「1」が消えました. やはりこの赤色はけっこう目を引きますね.
これで, ホーム画面を眺めても意識を持っていかれるものがなくなり, 「今は見ない」と判断する必要そのものがなくなりました. 集中力を削る要因が1つ減ったわけです.

# バッジを消しても困らない理由

- 通知そのものが止まるわけではない. (バナーやロック画面への表示は「通知」画面の別項目なので, 必要ならこちらも残せる.)

- 未読件数はアプリを開けば分かる. 「決めた時間に自分から見に行く」運用なら, バッジがなくても支障はない.

- 見逃したくないアプリはバッジを残せばよい. 全部消す必要はなく, 指定アプリだけをオフにすれば十分.

# まとめ

通知バッジがあると「見るか, 見ないか」という判断を常に迫られます.

集中したい時間帯にメールやSNSが気になってしまう人は, まず気になるアプリを1つだけバッジオフにしてみてください. 設定は10秒ほどで終わり, 気に入らなければ戻すのも一瞬です.
