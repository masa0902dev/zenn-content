# はじめに

昨日, email.claude.comから以下のようなメールが届きました.
そこには「Fable5にも使える$100分のクレジットが, 8月2日までにある操作をすれば貰えるよ」という内容がありました.

![Fable 5 has moved to usage creditsというメール](/images/claude-fable5-100dollers-credits-by-august-2th/email-from-email.claude.com.png =300x)

本記事では, 下記内容をまとめます:

- このクレジットを受け取るための条件

- このクレジットを受け取るための手順

- 実際に受け取った結果

- 使う際の注意点

## 本記事の対象読者
- Claude の Proプランを契約している方
- Fable 5を使ってみたい方 (Fable 5以外でも使えます)

# 対象プランと申請期限

対象プランは以下の通り. ただし, 日本時間では, 2026年7月20日14:59 時点でプランを保有している方のみ対象です.
Maxプラン・Enterpriseプランおよびフリートライアルは対象外です.

- **Pro プラン(月額/年額)**

- **Team プランの標準シート**

申請期限・有効期限は以下の通り.

- **申請期限: 日本時間では, 8月3日 15:59 まで**

- **有効期限: 日本時間では, 9月18日15:59 まで**

有効期限について, 公式記事には, 受け取りタイミングに関わらず一律の日付で失効すると明記されていますが, 筆者が実際にクレジットを受け取った後の画面には, 有効期限として"September 19, 2026"とありました. 公式の説明と少しずれていたので, 正確な期限は受け取り後の画面で確認するのが確実です.

なお, 有効期限までに使い切れなかった分は返金されません.
**Fable 5以外のモデルにも使えるクレジットなので, 有効期限内に使いまくりましょう.**

:::details 何故このクレジットがもらえるのか?
Fable 5が7月20日にpay-as-you-go(従量課金)へ移行したので, 利用にはusage creditsが必要になり, 契約中のプランのレート制限には含まれなくなりました.

この移行を機に, 1回限り$100分のusage creditsを付与し, Fable 5の体験使用をしてもらおう, という訳ですね. (Fable 5以外でもこのクレジットは使えます)
:::


# クレジットの受け取り手順

ここからは, Proプランでのクレジット受け取り手順を, Claude(デスクトップアプリ)のスクショとともに説明します.

まず, 左上のサイドバーを開くボタンをクリックします.

![サイドバーを開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow1_open-sidebar.png =400x)

次に, サイドバー左下のユーザーメニューをクリックします.

![ユーザーメニューを開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow2_open-usermenu.png =400x)

表示されたメニューから, Settingsを選択します.

![設定を開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow3_open-settings.png =400x)

設定画面が開いたら, 左メニューからUsageタブを開きます.

![使用量タブを開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow4_open-usage-tab.png =400x)

**Usageタブ内の最上部に, クレジットを受け取るためのボタンが表示されているはずです.** これをクリックすると, $100分のプロモーションクレジットがその場で付与されます.

# 受け取り結果の確認

受け取り後, Usageタブの下部の**Usage creditsのセクションに"$100.00 Promotional credit"という項目**が追加され, 有効期限とあわせて表示されるようになりました.

![$100クレジットの受け取りを確認](/images/claude-fable5-100dollers-credits-by-august-2th/flow5_check-the-credits.png =400x)


# 使う際の注意点

クレジットを実際に使うにあたって, いくつか設定しておくべき項目があります.

![creditsの使用と自動チャージに関する注意点](/images/claude-fable5-100dollers-credits-by-august-2th/caution-for-using-credits-and-auto-reload.png =400x)

💵 まず, "Turn on usage credits to keep using Claude if you hit a plan limit"というトグルをオンにしておく必要があります. これがオフのままだと, せっかく受け取ったクレジットも使用できません. Settings > Usage のUsage creditsのセクションから, ボタン一つでオンにできます.

$100クレジットを使い切った後も, 他にクレジットを持っていないのであれば, このトグルはオンのままで問題ありません.
他にクレジットを持っている場合は, **Monthly spend limit**を設定しておくと, 月の使用上限に達した時点でクレジットの消費が止まるので安心です. 筆者はMonthly spend limitを$10に設定しています. (ちなみに, クレジットはまとめて購入すると最大30%お得)

🚨 また, **Auto-reloadはオフにしておくことをおすすめします.** これがオンになっていると, クレジットを使い切った際に**自動で**追加クレジットが購入されます.
