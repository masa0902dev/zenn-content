# はじめに

昨日, email.claude.comから以下のようなメールが届きました.

![Fable 5 has moved to usage creditsというメール](/images/claude-fable5-100dollers-credits-by-august-2th/email-from-email.claude.com.png =400x)

内容を要約すると, Fable5にも使える$100分のクレジットを, 8月2日までにある操作をすれば貰える, というものでした.

本記事では, このクレジットをどうすれば貰えるのかを説明し, 実際に受け取った結果と, 使う際の注意点をまとめます.

# Fable 5がusage creditsへ移行

メールによると, Fable 5は7月20日にusage creditsへ移行しました. Fable 5自体は引き続き利用できますが, 利用には従量課金のusage creditsが必要になり, 契約中のプランのレート制限には含まれなくなりました.

この移行を機に, 1回限り$100分のusage creditsが付与されます. これは通常購入するクレジットと同じ扱いの標準的なusage creditsであり, Fable5に限らずどのモデルでも使用できます.

# 対象プランと申請期限

公式のヘルプ記事によると, 対象プランは以下の通りです.

- Pro プラン(月額/年額)

- Team プランの標準シート

Max プランおよび Enterprise プランは対象外です. また, フリートライアル中のユーザーも対象外となります.

申請期限と有効期限は以下の通りです.

- 申請期限: 2026年8月2日 11:59pm PT まで

- 有効期限: 受け取りから60日程度(筆者の場合は2026年9月19日までだった)

メール本文には有効期限として9月17日と記載されていましたが, 実際にクレジットを受け取った後の画面表示では9月19日が期限として表示されていました. 受け取るタイミングによって多少前後する可能性があるため, 実際の有効期限は受け取り後の画面で確認するのがよいでしょう.

なお, 有効期限までに使い切れなかった分は返金されません.

# クレジットの受け取り手順

ここからは, Proプランでのクレジットの受け取り手順を, PC版Claudeのスクリーンショットとともに説明します.

まず, 左上のサイドバーを開くボタンをクリックします.

![サイドバーを開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow1_open-sidebar.png =400x)

次に, サイドバー左下のユーザーメニューをクリックします.

![ユーザーメニューを開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow2_open-usermenu.png =400x)

表示されたメニューから, Settingsを選択します.

![設定を開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow3_open-settings.png =400x)

設定画面が開いたら, 左メニューからUsageタブを開きます.

![使用量タブを開く](/images/claude-fable5-100dollers-credits-by-august-2th/flow4_open-usage-tab.png =400x)

Usageタブ内のUsage creditsのセクションまでスクロールすると, クレジットを受け取るためのボタンが表示されているので, これをクリックします. クリックすると, $100分のプロモーションクレジットがその場で付与されます.

# 受け取り結果の確認

受け取り後, Usage creditsのセクションに"$100.00 Promotional credit"という項目が追加され, 有効期限とあわせて表示されるようになりました.

![$100クレジットの受け取りを確認](/images/claude-fable5-100dollers-credits-by-august-2th/flow5_check-the-credits.png =400x)

これで, $100分のusage creditsを受け取ることができました.

# 使う際の注意点

クレジットを実際に使うにあたって, いくつか設定しておくべき項目があります.

![creditsの使用と自動チャージに関する注意点](/images/claude-fable5-100dollers-credits-by-august-2th/caution-for-using-credits-and-auto-reload.png =400x)

まず, "Turn on usage credits to keep using Claude if you hit a plan limit"というトグルをオンにしておく必要があります. これがオフのままだと, せっかく受け取ったクレジットも使用できません. Settings > Usage のUsage creditsのセクションから, ボタン一つでオンにできます.

$100クレジットを使い切った後も, 他にクレジットを持っていないのであれば, このトグルはオンのままで問題ありません.

他にクレジットを持っている場合は, Monthly spend limitを設定しておくと, 月の使用上限に達した時点でクレジットの消費が止まるので安心です. 筆者はMonthly spend limitを$10に設定しています. なお, クレジットはまとめて購入すると最大30%お得になります.

また, Auto-reloadはオフにしておくことをおすすめします. これがオンになっていると, クレジットを使い切った際に自動で追加のクレジットが購入され, 課金されてしまいます.

# まとめ

Fable 5のusage creditsへの移行にともない, 2026年8月2日までにSettings画面から申請すると, $100分のusage creditsを受け取ることができます. 受け取ったクレジットは60日程度で失効する(筆者の場合は2026年9月19日でした)ため, 対象プランを契約しているのであれば早めに受け取っておくとよいでしょう.

受け取り後は, usage creditsのトグルをオンにし, 必要に応じてMonthly spend limitを設定した上で, Auto-reloadをオフにしておくことを忘れないようにしましょう.
