# おおまかなルール
- Zenn記事を書く際の最大の目標は, 多くの人に読んでもらうこと・多くの人から「いいね」をもらうこと, とする. (ただし, そのために過剰な装飾や誇張表現を使用することは避けること.)
- 文章は基本的に敬語で記述せよ.
  - ただし, 「ご自身」「ご確認ください」のような二重敬語・過剰な丁寧表現は避け, 「自身」「確認してください」程度の簡潔な敬語にする.
- 「〜ということです」「〜というのが正確なところのようです」のような, 情報量のない念押し・言い直しの表現(AIが書きがちな冗長表現)は避け, 言い切れる内容は言い切る.
- 記事の書き手自身を指す際は「筆者」ではなく「著者」で統一する.
- 基本的に, 全角記号ではなく半角記号を使用する. 特に, 下記の記号に注意する.
  - 「、」「。」ではなく「, 」「. 」を使用する.
  - 「（」「）」ではなく「(」「)」を使用する.
  - 全角スペースではなく半角スペースを使用する.
- マークダウンで過剰な装飾はしないように注意せよ.
- Zenn記事の書き方は, [ZennのMarkdown記法一覧](https://zenn.dev/zenn/articles/markdown-guide) を参考にせよ. (公式記事)

# その他の細かなルール
- 見出しはh1から使用する.
  - ただし, 補足的な内容(他の見出しの具体例・サブトピックなど)はh2以下にして, 内容の親子関係に応じて階層化することで読みやすくする.
- 見出しは, 基本的に「する」を省略して体言止めのようにする
  - 例: 「VPNの名称を変更する」ではなく「VPNの名称を変更」, 「vpnutilをインストールする」ではなく「vpnutilをインストール」
- キーバインドを説明する際に ⌘5 や ⌥↑ などの記号は使わず, cmd 5 や opt ↑ のように記述する

# 記事の完成度を上げるためのチェックリスト
- 記事を「完成」として報告する前に, 見出し・敬語などのルール確認だけでなく, 記事全体を通読して誤字や意味の通らない日本語がないか確認する.
- 記事の内容が正しいかどうかは, 著者が提供した情報だけでなく, 公式ドキュメントや信頼できる情報源を参照して確認する.
